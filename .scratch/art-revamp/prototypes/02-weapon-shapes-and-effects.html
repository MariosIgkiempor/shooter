Does a shapes-only weapon read with any punch?

Weapon-action-feel already tested plain icon-transform (pivot / angle / scale, no new art) on all eight weapons and rejected it three times: “sells the mechanic but not the punch.” This bench tests something that was never actually tried — the same transform, plus an enhanced shape-based effects layer (streaks, rotation, non-linear fade — none of which exist in particle.odin today) — against today’s basic dot-burst particles, one representative weapon per family. Timing values are the real resolved numbers from that map’s prototype tickets.

Each lane loops Trigger → Windup → Resolve continuously at the real cycle length above. Basic dots mirrors today’s spawn_particle_burst exactly: a flat-color radial fan of circles, linear fade. Enhanced shapes adds streak-shaped particles (elongated, oriented to their travel direction — nothing in particle.odin draws anything but a circle today), a brightening/expanding ring on impact, and ease-out fades instead of linear ones. The weapon body itself is the same silhouette and the same draw_weapon-style pivot/angle/scale motion in both modes — only the effect layer changes.
