# Typeface licences

One line per `.ttf` in this directory. The atlas builder's `TYPEFACES` table
(`vendor/atlas-builder/atlas_builder.odin`) lists which of these are baked and at
what sizes.

- `debug.ttf` — Geist Regular (Vercel, https://vercel.com/font), SIL Open Font License 1.1.
